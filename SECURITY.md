# Security policy

**Project maturity:** experimental 9front-derived kernel source. There is no production-support guarantee, supported product release, verified AMD64 boot, or published security-response SLA.

For a suspected vulnerability, avoid a public exploit-bearing issue. Contact a repository maintainer through a private GitHub security advisory report **if the feature is enabled**, or use another private channel that project maintainers have explicitly published. If no private channel is configured, do not assume a message address exists; ask project maintainers to enable private vulnerability reporting.

Include affected commits, minimal reproduction, impact and any proposed mitigation. Security fixes affecting upstream 9front should be coordinated with the relevant upstream maintainers when appropriate, without breaking responsible disclosure.

A normal upstream sync does not automatically ship security fixes. See `docs/UPSTREAM.md`.
