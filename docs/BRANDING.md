# Ryzova identity and visual/content rules — Phase 2

**Project:** Ryzova Kernel  
**Project organization:** RyzovaTech  
**Future official OS:** RyzovaOS (not shipped by this repository)  
**Tagline:** A New Life for a Forgotten Vision  
**Existing repository URL:** `https://github.com/RyzovaTech/Ryzova-Kernal` — deliberately left unchanged to preserve links.

## Naming

- Use **Ryzova Kernel** in prose and documentation. “Kernal” is only the pre-existing GitHub repository spelling.
- Describe the technical origin accurately as **“derived from 9front / Plan 9”**, not as an official 9front release or endorsement.
- Do not call an unchanged imported 9front build a novel Ryzova Kernel release.
- “RyzovaOS” names the future operating system on top of the kernel; it is not a synonym for the upstream 9front source tree.

## Source credit and marks

Retain all original Plan 9/9front copyright notices. Use Ryzova names and logos only where the actual rights holder has authorized their use; source-code permissions do not automatically authorize marks. See [`TRADEMARKS.md`](../TRADEMARKS.md).

For third-party variants, the technical compatibility label “based on Ryzova Kernel” is appropriate, but make independent maintenance clear.
